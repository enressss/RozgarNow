# 🚀 RozgarNow  
### 🏛️ Government Job Vacancy Alert & 📚 Syllabus Tracking Platform

RozgarNow is a **modern, full-stack web application** designed to help government job aspirants **discover vacancies, track syllabi, and stay updated with real-time alerts** — all from a single, reliable platform.

📢 No more checking multiple government websites  
⏰ No more missed deadlines  
📄 No more confusion about syllabus & exam patterns  

---

## 🎯 Why RozgarNow?

Government job information is **scattered, delayed, and difficult to track**.  
RozgarNow solves this by acting as a **centralized aggregator** that pulls data only from **official government portals** and presents it in a clean, structured, and user-friendly way.

---

## ✨ 🚀 Features

- 📢 **Real-time Government Job Alerts**
- 🗂️ **Browse vacancies** from multiple official sources
- 🔍 **Advanced Search & Filters** (qualification, department, state, deadlines)
- ⭐ **Bookmark jobs** to view later
- 📚 **Syllabus Tracker** for multiple exams
- 🔔 **Personalized Notifications** (Email / Push)
- ⏳ **Deadline reminders**
- 🧑‍💻 **Admin dashboard** for managing sources & scrapers
- 🎨 **Clean & responsive UI** using **Tailwind CSS & shadcn/ui**
- ⚡ **Built using React + TypeScript + Vite**

## 🏗️ System Architecture

### 🖥️ Frontend
- ⚛️ React
- 🟦 TypeScript
- ⚡ Vite
- 🎨 Tailwind CSS
- 🧩 shadcn/ui

### 🖧 Backend
- 🟢 Node.js
- 🚀 Express
- 🔐 JWT Authentication
- 🔁 REST APIs

### 🗄️ Database
- 🐘 PostgreSQL / MySQL
- ⚡ Optional Redis (Caching)

### 🔔 Notifications
- 📲 Firebase Cloud Messaging
- 📧 SMTP Email Service

### 🕷️ Scraping Layer
- 🤖 Modular scrapers per government portal
